📡 PA Monitor

SMC 价格提醒工具 · 我负责分析，程序负责盯价格 pa-monitor

它是干什么的

在 TradingView 上用 SMC 找到关注的 POI 后，只输入 币种 + 一个触发价格。 后端持续盯 OKX 实时行情，价格第一次到达就推手机提醒 —— 收到后再打开图表看价格行为。
  • 程序不判断多空、不识别 SMC、不下单
  • 方向自动判断：触发价在当前价下方 → 跌到即提醒；上方 → 涨到即提醒
  • 两级提醒：距目标 0.5% 先来一条「接近」，到价再来一条「到价」，各只发一次

工作流

TradingView 分析 → 找到 POI → 面板填「HYPE / 51.20」
→ 程序自动算方向、订阅该币种行情
→ 后台盯 OKX（关浏览器、关电脑上的网页都不影响）
→ 接近 → ⚠️ 提醒 ｜ 到达 → 🚨 提醒（微信 + Discord）
→ 打开 TradingView，自己看 Reaction / Displacement / MSB / BOS，自己决定做不做

面板与数据

  • 面板：本机 http://127.0.0.1:8787/（同一 Wi-Fi 下手机可访问）
  • 行情：OKX 公共 WebSocket，只读，不需要 API Key，不下单
  • 存储：SQLite，记录创建价、触发方向、状态、接近是否已发、是否已触发
  • 提醒状态：监控中 / 接近目标 / 已触发 / 已暂停；已触发保留在历史里，可重新激活或删除
